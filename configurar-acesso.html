Configure a senha do seu ateliê.

Este arquivo gera os valores de configuração no seu navegador. A senha não é enviada para nenhum serviço.

Copie estes valores no Netlify

Em Project configuration → Environment variables, adicione as duas variáveis abaixo, disponíveis para Functions. Depois publique novamente o projeto.

Para entrar no sistema, use a senha que você criou, e não esses códigos.

Não coloque esses valores no GitHub ou no chat. Guarde a senha em local seguro. Para trocar a senha no futuro, gere novos valores, altere as variáveis no Netlify e publique novamente; as sessões anteriores deixarão de funcionar.
