Como funciona o salvamento online?

Pedidos, produtos e exclusões ficam salvos online neste site. Use o mesmo endereço e a mesma senha no computador e no celular. Aguarde a mensagem Salvo online antes de fechar.

É necessário estar conectado à internet para salvar. Se houver falha, mantenha a tela aberta e use Baixar rascunho. O sistema confere alterações de outros aparelhos antes de salvar e atualiza a lista automaticamente quando nenhum formulário está aberto.

Use Importar backup para reunir os arquivos JSON da versão anterior. Registros com o mesmo número e conteúdo diferente são preservados com um novo número. Produtos com o mesmo nome mantêm o preço já salvo online.
